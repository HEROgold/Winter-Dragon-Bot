# wd-core

Shared domain helpers above the transport: the bot's default intents and permissions, and `PackageVersion`. Transport types (`Intents`, request payloads) and the Sentry setup live in wd-discord.

- **Depends on:** wd-config, wd-discord, wd-types.
- **Start here:** `wd_core.constants`.
- **API reference:** [wd_core](../docs/reference/wd-core.md)
