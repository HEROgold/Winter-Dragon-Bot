Privacy policy

This policy covers Winter Dragon: the Discord bot and this dashboard. Last changed {{ updated }}.

Terms used in this policy

Winter Dragon
The Discord bot and this dashboard together.
Operator
HEROgold, the one person who runs Winter Dragon and decides what data it processes. Under the GDPR this is the "controller".
Dashboard
This website, where you sign in with Discord to see and manage your data.
Discord server
A community on Discord that the bot has been added to. Discord's own documentation calls it a "guild".
Discord ID
The number Discord gives every user, server, channel and message. Your Discord user ID identifies your Discord account.
Your data
Rows Winter Dragon stores because you used a feature. Each one holds your Discord user ID.
Server data
Rows a Discord server's admins created, such as its settings. Server data belongs to the server, not to one member.
Command usage
A count, per day, of how often a user ran each command in each Discord server.
Linked Riot account
A Riot Games account you proved is yours and connected to your Discord user ID on the dashboard.
Riot Sign On
Riot's own login page. After you sign in there, Riot tells Winter Dragon which account you signed in with. Winter Dragon never sees your Riot password.
Riot ID
Your name and tag in League of Legends, such as Name#EUW. You can change it.
PUUID
Riot's permanent ID for an account. It doesn't change when the Riot ID changes.
Region
The Riot server an account plays on, such as EUW (Europe West).
Clash
Riot's weekend team tournaments in League of Legends.
Ranked 5s, Flex, Solo/Duo
League of Legends' ranked queues: five-player premade teams, groups of any size, and one or two players.
Pair result
For two linked members: how many games they played on the same team, and how many of those they won.
Collection
Winter Dragon fetching data about a linked Riot account from Riot.
Hidden
The first stage of deleting. Hidden data isn't shown or used anywhere, but can still be restored.
Purged
Removed from the database permanently. Purged data can't be restored.
Error report
A message Winter Dragon sends to Sentry when something fails: what failed, where in the code, and the request or command it was handling.
Performance trace
A record of how long a command or page took, step by step.
Log message
A line of text Winter Dragon writes about what it's doing, such as "sent reminder 12".
IP address
The network address of your device or connection when you open the dashboard.
Request headers
Details your browser sends with every page request, such as its version, language and cookies.
Cookie
A small piece of data the dashboard stores in your browser and your browser sends back on each request.
Backup
A copy of the whole database, kept to restore it after a failure.
Legal basis
The reason the GDPR accepts for processing data: needed for a service you use, your consent, or a legitimate interest.

Operator

Winter Dragon is a hobby project run by one person, HEROgold, in the Netherlands. The General Data Protection Regulation (GDPR, Dutch: AVG) applies.

Contact the operator first about any problem: {{ email }}, the support server (/invite guild), or GitHub issues for anything public.

Data Winter Dragon stores

  • Your data: what you create with a command, in any Discord server. Examples: reminders, refuels, Steam sale alerts, voice channel settings, teams, tournament sign-ups and game progress. Each row holds your Discord user ID.
  • Server data: what a server's admins set up, such as channels, welcome messages, roles and tournaments. It belongs to the server.
  • Command usage: per day, how often you used each command in each server.
  • Discord IDs of the users, servers, channels and messages that a stored row refers to.

Winter Dragon doesn't store message content or presence. Your data lists every row stored about you.

Riot accounts

League of Legends features need a linked Riot account. You link it on this dashboard, with Riot Sign On or with the Riot connection on your Discord profile. Linking an account is consent to collecting this data about it:

  • Riot ID, PUUID and region;
  • official ranks;
  • Clash teams and games, then Ranked 5s, Flex and Solo/Duo games;
  • per pair of linked members: games played together and games won.

Winter Dragon stores the Riot ID, PUUID, region and pair results. It fetches games from Riot when needed and doesn't store them. On Your data you can switch collection off, delete collected data, or unlink the account. Deleting data doesn't switch collection off. Linking requires age 16 or older, or consent from a parent or guardian.

Dashboard sign-in and cookies

Sign-in uses Discord. Winter Dragon reads your Discord user ID, user name, avatar and server list, then revokes the Discord token. No Discord token is stored. The list of servers you share with the bot is kept in memory for 15 minutes.

Cookies: a signed session cookie (up to 14 days) and a time zone cookie. No tracking or advertising cookies.

Legal basis

  • Your data and server data: needed to provide the features you use (GDPR article 6(1)(b)).
  • Riot account data: consent, given by linking (article 6(1)(a)). Unlinking withdraws it.
  • Error reports and backups: legitimate interest in keeping Winter Dragon working (article 6(1)(f)).

Retention

  • Your data is kept until you delete it or the feature no longer needs it.
  • Deleted data is hidden at once and purged {{ retention_days }} days later, or at once if you choose that. Hidden data is only used to restore it at your request.
  • Where your data is part of another member's history, such as a tournament match, your user ID is removed instead.
  • Server data is purged {{ retention_days }} days after a server removes the bot, unless the bot is added back before then.
  • Command usage is purged after {{ usage_months }} months.
  • A backup is made before every update of Winter Dragon and stored on the same server. The newest {{ backups_kept }} backups are kept and older ones are deleted, so purged data stays in backups until {{ backups_kept }} newer backups exist.

Your rights

You can access, correct, delete and export your data, object to its use, and withdraw consent. Your data handles viewing and deleting. For other requests, email {{ email }}.

You can lodge a complaint with the Dutch data protection authority, the Autoriteit Persoonsgegevens.
